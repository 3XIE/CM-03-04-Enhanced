# Championship Manager 03/04 Enhanced

Некоммерческий проект развития Championship Manager 03/04. Версия 2026.0.

## Установка

Скачайте **CM0304-Enhanced-2026.0-Setup.exe** в разделе [Releases](https://github.com/3XIE/CM-03-04-Enhanced/releases/latest), выберите папку установки и при необходимости создайте ярлык на рабочем столе. Установщик содержит игру и лаунчер; интернет для установки, Python и отдельная установка .NET не требуются. Windows 10/11 x64.

Запускайте **CM Enhanced Launcher.exe** из папки игры. Он проверяет обновления сборки, целостность файлов и позволяет менять шрифты и газон. Сохранения и пользовательские настройки сохраняются при обновлениях. Лаунчер использует папку, в которой находится; выбирать её отдельно не нужно.

В комплекте четыре скина с подсветкой высоких характеристик, три набора шрифтов и два варианта газона. Скины выбираются в игре. Multi-colored отдельно отсутствует: его подсветка перенесена в остальные скины. Логотипы клубов, турниров и сборных в базовую сборку не включены.

## Поддержать проект

Проект распространяется на некоммерческой основе и разрабатывается на энтузиазме. Для продолжения анализа кода игры и внесения правок необходимо оплачивать подписку на ИИ. Буду благодарен любой финансовой поддержке.

Добровольные пожертвования: **+7 904 916-20-60, Альфа-Банк**.

## Исходники лаунчера и установщика

`src/Launcher` — WPF-лаунчер, `src/Core` — проверка пакетов и установка с восстановлением при ошибке, `src/Setup` — автономный WPF-установщик. Исходники оригинальной игры здесь отсутствуют.

Для сборки нужен .NET SDK 10 с Windows Desktop и Windows x64:

```powershell
./build.ps1
dotnet run --project tests/Tests.csproj -c Release
```

Для подготовки полной сборки также нужен Python 3 и исходная локальная папка игры. Команда запускается из корня проекта, выходная папка должна быть новой:

```powershell
./tools/build_release.ps1 -Game 'C:/Games/CM0304' -Python 'python' -Output 'release-packages/2026.0-final'
```

Перед упаковкой в `data/graphics/textures/grass/1` должны лежать девять классических GIF; корень `grass` в исходной папке для этой команды должен быть пуст от GIF. В архиве классический вариант будет установлен в активный корень. Готовые исходники дополнений лежат в `addon-sources`; пути в каталоге разрешаются относительно файла каталога.

Проверка итоговых пакетов:

```powershell
python -m unittest discover -s tools -p 'test_*.py'
dotnet run --project tests/Tests.csproj -c Release -- --manifest release-packages/2026.0-final/manifest.json
```

Полная инструкция публикации: [PUBLISH_GITHUB_RU.md](PUBLISH_GITHUB_RU.md).

Обновление игры работает через `releases/latest/download/manifest.json`. Автоматическое обновление самого лаунчера не реализовано: новый EXE распространяется отдельным ZIP или установщиком. Встроенные шрифты и газон доступны без интернета после установки, остальные пакеты — после добавления в каталог релиза.
