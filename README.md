# Championship Manager 03/04 Enhanced

Некоммерческий проект развития Championship Manager 03/04. Текущая версия 2026.1.

## Установка

Скачайте **CM0304-Enhanced-Setup.exe** в разделе [Releases](https://github.com/3XIE/CM-03-04-Enhanced/releases/latest), выберите папку установки и при необходимости создайте ярлык на рабочем столе.

Запускайте **CM Enhanced Launcher.exe** из папки игры. Он проверяет обновления сборки, целостность файлов и позволяет менять некоторые настройки игры. Сохранения и пользовательские настройки сохраняются при обновлениях.

В комплекте четыре скина с подсветкой высоких характеристик, три набора шрифтов и два варианта газона. Скины выбираются в игре. Логотипы клубов, турниров и сборных в базовую сборку не включены.
